# ORIGINAL

موقع عربي ثابت لشركة ORIGINAL للتصميم الداخلي والديكور والتشطيبات. مبني بـ Next.js App Router ويُصدَّر كمجلد `out/` للرفع على Hostinger.

## المحتوى النموذجي

لا توجد حتى الآن صور أو بيانات تواصل أو عنوان موثّق للشركة.

- كل الأعمال في `src/data/projects.ts` معلّمة بـ `isPlaceholder: true`. العناوين والسنوات والوصف والصور نماذج بصرية من Unsplash، وليست مشاريع منفَّذة.
- الخدمات في `src/data/services.ts` أمثلة، وتحتاج تأكيد الشركة.
- خطوات العمل في `src/data/process.ts` مقترحة، وتحتاج مراجعة على أسلوب العمل الفعلي.
- لا تُعرض شهادة أو جائزة أو اسم عميل أو رقم تواصل مخترع.

لاستبدال الصور: ضع ملفات WebP في `public/images/` بنفس المسارات، أو عدّل المسارات داخل بيانات المشروع. الصورة الاحتياطية: `public/images/fallback.webp`.

## الإعدادات

كل بيانات الشركة في `src/data/site-config.ts`:

- `phone`
- `whatsappUrl` رابط كامل مثل `https://wa.me/201000000000`
- `email`
- `address`
- `mapUrl` رابط فتح الموقع في خرائط جوجل.
- `mapEmbedUrl` رابط الإطار المعروض في قسم الزيارة.
- `social.instagram` و `social.facebook`
- `domain` عند معرفة الدومين، مثال `https://example.com`، لتفعيل الرابط المعياري و`metadataBase`.

التواصل مباشر عبر واتساب والهاتف والبريد. لا يوجد نموذج إرسال.

## الصور والاستضافة الثابتة

`output: 'export'` و `trailingSlash: true` لأن Hostinger يخدم ملفات ثابتة. تحسين صور Next.js يحتاج خادمًا، لذلك `images.unoptimized` مفعّل، والصور تُحضَّر مسبقًا بأمر:

```bash
npm run images
```

Cache Components و Partial Prefetching غير مفعّلين لأنهما يحتاجان تشغيل Node.js، وهو غير متاح على الاستضافة الثابتة.

## البناء والرفع

```bash
npm run build
```

ارفع **محتوى** مجلد `out/` إلى جذر الاستضافة، بما فيه `.htaccess`. الملف يفرض الشرطة المائلة في نهاية المسارات ويضبط التخزين المؤقت للملفات الثابتة.

## الرجوع من صفحة المشروع

الضغط على عمل يحفظ مسار الصفحة وموضع التمرير. زر «العودة» يرجع عبر سجل المتصفح إلى ذلك المكان، ثم تعاد استعادة الموضع بعد الرسم.
